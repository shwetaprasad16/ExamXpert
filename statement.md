# Project Statement

## Title
EXAMXPERT – Competitive Examination Preparation & Performance Analysis System

## Problem Statement
Competitive-exam students need a structured way to practice questions, attempt timed tests, calculate results and identify topics requiring more revision. EXAMXPERT combines these activities in one Java application.

## Objectives
1. Provide a structured mock-test environment.
2. Support multiple competitive-examination categories.
3. Automatically evaluate answers.
4. Calculate score, accuracy, correct, wrong and skipped questions.
5. Analyze performance at topic level.
6. Detect weak topics.
7. Generate rule-based study recommendations.
8. Demonstrate Java programming concepts through a real-world application.

## Scope
The current system supports GATE, SSC, BANKING, UPSC and CAT. Each test contains 20 questions and has a 20-minute timer. Data is stored using text files.

## Target Users
College students and competitive-examination aspirants.

## Major Functional Modules
1. Student Management
2. Question Bank Management
3. Mock Test Management
4. Performance Analysis
5. Recommendation Module
6. File Storage

## Input
Student details, exam, subject, answers and navigation commands.

## Output
Test result, accuracy, topic-wise performance, weak topics and study recommendations.

## Non-Functional Requirements
Usability, performance, reliability, maintainability, scalability, resource efficiency and error handling.

## Storage
Questions, student records and performance records are stored in text files under `data/`.
